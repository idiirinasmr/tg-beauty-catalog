# TESTING.md — Руководство по тестированию

## Общая информация

**Проект:** Telegram Mini App — каталог услуг бьюти-мастера
**Стек:** HTML + CSS + JS (без фреймворков), Telegram Web App SDK
**Бот:** @Krasa555bot (название: БиутиСалон)
**Продакшен:** https://idiirinasmr.github.io/tg-beauty-catalog/
**Репозиторий:** https://github.com/idiirinasmr/tg-beauty-catalog
**Деплой:** GitHub Pages, автоматический при пуше в master (workflow: `.github/workflows/deploy.yml`)
**Деплоится папка:** `tg-app/` как корень сайта

## Как запустить локально

### Вариант 1: Python
```bash
cd tg-app
python -m http.server 8080
```
Открыть: http://localhost:8080

### Вариант 2: npx
```bash
cd tg-app
npx serve .
```

В обычном браузере работает **заглушка Telegram SDK** (файл `index.html`, строки 10–70). Заглушка эмулирует: MainButton, BackButton, HapticFeedback, sendData, и тестового пользователя `{first_name: 'Тест', id: 123, username: 'test'}`.

## Как тестировать в Telegram

1. Открыть Telegram (мобильный или десктоп)
2. Найти бота **@Krasa555bot**
3. Нажать кнопку **«Записаться»** внизу слева (Menu Button)
4. Откроется Mini App

### Сброс состояния для повторного тестирования

Приложение запоминает в `localStorage` два флага:
- `onboarding_done` — онбординг показан
- `offer_shown` — модалка-оффер показана

Чтобы сбросить оба и увидеть все экраны заново:
- В браузере: открыть https://idiirinasmr.github.io/tg-beauty-catalog/?reset
- В Telegram: сброс невозможен через URL, нужно очистить данные Mini App в настройках Telegram (Настройки → Хранилище → Очистить данные бота) или удалить/переустановить Telegram

## Структура экранов

Приложение состоит из 5 экранов + 1 модалка. Все экраны — div-секции с классом `.screen` в одном файле `index.html`.

| # | ID экрана | Название | Когда видно |
|---|-----------|----------|-------------|
| 0 | `#screen-onboarding` | Онбординг (приветствие) | Первый визит |
| 1 | `#screen-catalog` | Каталог (главный экран) | Всегда после онбординга |
| 2 | `#screen-detail` | Детали услуги | При нажатии на услугу |
| 3 | `#screen-confirm` | Подтверждение записи | При нажатии «Записаться» |
| 4 | `#screen-success` | Успех | После подтверждения |
| — | `#offer-overlay` | Модалка-оффер (скидка 15%) | Первый визит, поверх каталога |

## Известные особенности

1. **Портфолио** — сейчас заглушки (эмодзи на градиентах). Папка `tg-app/img/` пуста. Для замены на фото нужно доработать `renderPortfolio()` и `fillDetailScreen()`.
2. **Бот не обрабатывает сообщения** — нет серверной части. Команды `/start` и `/help` зарегистрированы, но бот на них не отвечает. `sendData()` отправляет данные, но без работающего бота они никуда не приходят.
3. **Отзывы захардкожены** — 3 отзыва прямо в HTML, не из базы данных.
4. **Имя мастера дублируется** — в `app.js` (объект `master`) и в нескольких местах `index.html`. При смене имени нужно менять в обоих файлах.
5. **bot/setup.js** требует Node.js 18+ (используется глобальный `fetch`). На текущей машине Node.js не установлен, настройка бота выполнялась через curl.
