# Бриф: Каталог услуг бьюти-мастера — Telegram Mini App

> Дата: 2026-03-10
> Версия: MVP (v1)

---

## 1. Общая концепция

**Продукт:** Telegram Mini App — каталог услуг бьюти-мастера с возможностью записи.

**Флоу:** Клиент открывает бота → нажимает кнопку → видит услуги с ценами → нажимает «Записаться» → мастер получает заявку.

**Стек:** HTML + CSS + vanilla JS (без фреймворков). Бандл < 50KB.

**Дизайн:** Нативный Telegram — CSS-переменные темы, MainButton, BackButton, HapticFeedback. Светлая и тёмная тема автоматически.

**Язык интерфейса:** Русский.

---

## 2. Список экранов MVP

```
[Экран 1] Каталог услуг (главный)
     ↓ нажатие на карточку
[Экран 2] Детали услуги
     ↓ MainButton «Записаться»
[Экран 3] Подтверждение записи
     ↓ MainButton «Подтвердить запись»
[Экран 4] Успех
     ↓ автоматическое закрытие / кнопка «Закрыть»
```

```
│  │ Маникюр   │ │ Педикюр   ││
│  │ 60 мин    │ │ 90 мин    ││
│  │ 1 500 ₽   │ │ 2 000 ₽   ││
│  └───────────┘ └───────────┘│
│                             │
│  ┌───────────┐ ┌───────────┐│
│  │  [фото]   │ │  [фото]   ││
│  │ Покрытие  │ │ Наращив.  ││
│  │ гель-лак  │ │ ногтей    ││

│  └───────────┘ └───────────┘│
│                             │
└─────────────────────────────┘
```

**Элементы:**

| Элемент | Описание | Размер/стиль |
|---------|----------|-------------|
| Шапка мастера | Фото (аватар 48px) + имя + специализация | Фиксированная сверху |
| Сетка карточек | 2 колонки на мобильном | CSS Grid, gap 12px |
| Карточка услуги | Фото + название + длительность + цена | border-radius 12px, фон `secondary_bg_color` |
| Фото в карточке | Фото результата работы | aspect-ratio 1/1, object-fit cover, border-radius 8px |
| Название услуги | Жирный, 15px | `text_color` |
| Длительность | 13px, серый | `hint_color` |
| Цена | Жирный, 16px | `link_color` или акцентный |

**Действия:**
- Нажатие на карточку → переход на Экран 2 (детали)
- HapticFeedback `selectionChanged` при нажатии

**Нативные элементы Telegram:**
- `BackButton` — скрыт (это главный экран)
- `MainButton` — скрыт (пока ничего не выбрано)

## 4. Данные, отправляемые в бота (sendData)

```json
{
  "action": "booking",
  "service": "Маникюр",
  "price": 1500,
  "duration": 60,
  "user_name": "Клиент",
  "user_id": 123456789
}
```

**Что делает бот после получения:**
1. Формирует сообщение мастеру:
   ```
   📋 Новая заявка!
   Услуга: Маникюр
   Цена: 1 500 ₽
   Длительность: 60 мин
   Клиент: @username (Имя)
   ```
2. Отправляет мастеру (в чат бота)
3. Мастер пишет клиенту напрямую в Telegram

## 7. Технические требования

### Обязательные вызовы API

```javascript
// При загрузке
Telegram.WebApp.ready();
Telegram.WebApp.expand();

// Навигация
Telegram.WebApp.MainButton.setText('...');
Telegram.WebApp.MainButton.show();
Telegram.WebApp.MainButton.hide();
Telegram.WebApp.MainButton.onClick(callback);
Telegram.WebApp.MainButton.showProgress();
Telegram.WebApp.MainButton.hideProgress();

Telegram.WebApp.BackButton.show();
Telegram.WebApp.BackButton.hide();
Telegram.WebApp.BackButton.onClick(callback);

// Обратная связь
Telegram.WebApp.HapticFeedback.impactOccurred('light');
Telegram.WebApp.HapticFeedback.notificationOccurred('success');
Telegram.WebApp.HapticFeedback.selectionChanged();

// Отправка данных
Telegram.WebApp.sendData(JSON.stringify(data));

// Закрытие
Telegram.WebApp.close();
```

## 9. Чего НЕ будет в первой версии (MVP)

| Функция | Почему не сейчас | Когда |
|---------|-----------------|-------|
| Календарь записи | Усложняет MVP, нужен бэкенд с расписанием | v2 |
| Выбор даты и времени | Мастер сам согласует через Telegram | v2 |
| Онлайн-оплата | Требует интеграцию с платёжной системой | v2 |
| Корзина (несколько услуг) | Для MVP достаточно одной услуги | v2 |
| Регистрация/авторизация | Telegram уже знает пользователя | Никогда |
| Отзывы и рейтинг | Нужна база данных | v2 |
| Уведомления-напоминания | Нужен бэкенд + cron | v2 |
| История записей | Нужна база данных | v2 |
| Поиск по услугам | При 6 услугах — не нужен | v2 (если 15+) |
| Фильтры/категории | При 6 услугах — не нужны | v2 (если 15+) |
| Админ-панель для мастера | Мастер редактирует код напрямую или через CMS | v2 |
| Мультиязычность | Только русскоязычная аудитория | Не планируется |
| Анимации переходов | Nice-to-have, не критично | v1.1 |

## 10. Порядок разработки

```
Шаг 1. Подготовка
├── Создать бота через @BotFather
├── Получить токен бота
└── Настроить Menu Button (ссылка на Mini App)

Шаг 2. Вёрстка Mini App (index.html + style.css)
├── Экран 1 — каталог (сетка карточек)
├── Экран 2 — детали услуги
├── Экран 3 — подтверждение
└── Экран 4 — успех

Шаг 3. Логика Mini App (app.js)
├── Переключение экранов (show/hide div)
├── MainButton — текст и обработчики для каждого экрана
├── BackButton — навигация назад
├── HapticFeedback — на ключевые действия
├── sendData() — отправка выбора в бота
└── Заполнение карточек из массива services

Шаг 4. Telegram-бот (bot.py)
├── Обработка /start — приветствие + кнопка Mini App
├── Обработка web_app_data — получение заявки
└── Пересылка заявки мастеру

Шаг 5. Хостинг и деплой
├── Mini App → GitHub Pages (HTTPS)
├── Бот → VPS или Railway/Render
└── Привязать URL Mini App в BotFather

Шаг 6. Тестирование
├── iOS (Telegram для iPhone)
├── Android (Telegram для Android)
├── Desktop (Telegram Desktop)
├── Светлая тема
└── Тёмная тема
```
