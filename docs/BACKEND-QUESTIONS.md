## Контекст

Задача: доработать приложение так, чтобы оно стало универсальным SaaS-платформой.
Любой мастер сможет:
- Запустить своего бота и приложение с нуля
- Добавить свои фотографии и услуги
- Подключить своего бота самостоятельно
- Получить индивидуальное приложение под свой бренд
- Бот = консультант для клиентов
- Бесплатно: 5 услуг
- Платно: подписка, расширенный функционал, White Label
