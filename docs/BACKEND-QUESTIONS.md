# Вопросы перед составлением BACKEND-PLAN.md

> Дата: 12 марта 2026
> Статус: ответы получены 13 марта 2026

## Контекст

Задача: доработать приложение так, чтобы оно стало универсальным SaaS-платформой.
Любой мастер сможет:
- Запустить своего бота и приложение с нуля
- Добавить свои фотографии и услуги
- Подключить своего бота самостоятельно
- Получить индивидуальное приложение под свой бренд
- Бот = консультант для клиентов
- Бесплатно: 5 услуг
- Платно: подписка, расширенный функционал, White Label

---

## Вопрос 1: Бот — один или у каждого мастера свой?

**Вариант А:** Один центральный бот (например, @BeautyAppBot). Мастер регистрируется через него, клиенты тоже заходят через него, но видят только своего мастера.

**Вариант Б:** Каждый мастер создаёт своего бота через BotFather. Наш сервер подключается к нему. Клиенты заходят в бота мастера и видят только его.

**Ответ:** Вариант Б — каждый мастер создаёт свой бот. Один сервер обслуживает всех мастеров. По ID бота сервер определяет, чей каталог показать. Клиенты одного мастера не знают о существовании другого. Это классическая SaaS-модель.

---

## Вопрос 2: Как мастер настраивает своё приложение?

**Вариант А:** Через бота (чат-бот задаёт вопросы: «Как вас зовут?», «Загрузите фото», «Добавьте услугу»).

**Вариант Б:** Через админ-панель (веб-страница с формами, где мастер заполняет профиль, загружает фото, добавляет услуги).

**Вариант В:** Оба варианта.

**Ответ:** Вариант В — оба: и через Mini App (прямо в приложении), и через админ-панель (веб-страница с формами для профиля, фото, услуг).

---

## Вопрос 3: Подписка — как оплачивает мастер?

- Через Telegram Payments (Stars / банковская карта прямо в боте)?
- Через внешнюю платёжную систему (ЮKassa, Stripe)?
- Вручную (перевод на карту, потом активация)?
- Пока не знаешь — решим позже?

**Ответ:** Два варианта: 1) Через внешнюю платёжную систему (ЮKassa, Stripe). 2) Вручную (перевод на карту, потом активация).

## Вопрос 5: Бот-консультант — что он умеет?

- [ ] Отвечает на вопросы клиентов автоматически (FAQ)?
- [ ] Присылает напоминания о записи?
- [ ] Рассылает акции/новости от мастера?
- [ ] Принимает заявки и уведомляет мастера?
- [x] Что-то ещё?

**Ответ:** Все четыре пункта — да:
1. Отвечает на вопросы клиентов автоматически (FAQ). Если не знает ответ — переводит на мастера.
2. Присылает напоминания о записи.
3. Рассылает акции/новости от мастера.
4. Принимает заявки и уведомляет мастера.
Дополнительно (предложение): приветственное сообщение при /start, сбор отзывов после визита, статистика записей для мастера.

## Вопрос 6: Технические вопросы

- **Домен:** Есть свой домен или нужны поддомены (например, `anna.beautyapp.ru`)?
- **Хостинг:** Есть VPS/сервер или нужен облачный (Railway, Render)?
- **Бюджет на инфраструктуру:** Готова платить за сервер (~500-2000 руб/мес) или бесплатно на старте?

**Ответ:** VPS на Бегете (полный контроль). Supabase для базы данных (бесплатный тариф на старте). Хочу полный контроль над данными и инфраструктурой. Сервер подключу сама, а настройку сделает Claude.
