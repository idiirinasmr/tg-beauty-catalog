### 26.10.2026 — Построена SaaS-платформа (этапы 1–8, ветка feature/saas-platform)
- **Совет (council)** по 3 спорным решениям: бот доступен на Free; очередь в памяти вместо BullMQ+Redis (статус рассылки в БД); webhooks в проде, polling локально
- **server/** — Fastify + Prisma + grammy: таблицы БД, вход через Telegram (Login Widget / initData) + JWT, API мастера/клиента/владельца, лимиты Free/Pro, MAX_MASTERS
- Мульти-бот: боты мастеров + бот владельца, токены AES-256-GCM, бот-консультант (FAQ → пересылка мастеру), напоминания за 24/2 ч, сбор отзывов
- Платежи: ЮKassa (перепроверка через API) + перевод на карту; cron просрочки подписок; ежедневный отчёт 21:00
- **admin/** — панель мастера (тёплый «салонный» дизайн); **platform-admin/** — панель владельца
- **tg-app/** — каталог из API по ?bot=USERNAME, запись через /api/booking; демо-режим для GitHub Pages сохранён
- Проверки: тесты; code-review (все находки исправлены); прогон в браузере 375px; security-review — уязвимостей не найдено

### 27.10.2026 — Настройка под ключ
- Ветка `feature/saas-platform` отправлена на GitHub
- Услуга «под ключ» (мастер ничего не делает, только платит): владелец создаёт мастера в панели платформы, заполняет каталог в режиме настройки, мастер один раз нажимает ссылку, владелец отмечает оплату. Цена — «Обсуждается», сумма вводится при отметке «Оплачено»
- Предложение «Настроим всё за вас» на экранах входа, регистрации и на главной панели мастера
