# Промпт: Настройка бота + онбординг + поделиться

Настрой моего Telegram-бота полностью.
Токен бота в файле .env.

Бот открывает Mini App — каталог бьюти-услуг с записью к мастеру.

Через Telegram Bot API:
1. Установи описание бота (setMyDescription) — 2-3 предложения
2. Установи короткое описание (setMyShortDescription) — одно предложение
3. Установи команды (setMyCommands) — /start, /help
4. Установи Menu Button — кнопка «Записаться»

В приложении (Mini App):
5. Экран приветствия (онбординг) — обращение по имени, 3 пункта, кнопка «Начать»
6. Кнопка «Поделиться с другом» — на экране успеха

Русский язык, дружелюбный тон, без пафоса.
